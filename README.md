# Syllabus Linker

build this 

Syllabus-to-Library Catalog Linker: An app where students upload a course syllabus PDF, and the tool automatically parses it to find required readings and cross-references them with the university library's digital API or physical shelf location.

Key features: PDF text parsing (OCR), book availability checker, and direct links to digital journals.
